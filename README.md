# KINEA Pilates
Sitio estático listo para publicar en GitHub Pages.

El formulario de reservas está configurado para abrir WhatsApp de KINEA con un mensaje prearmado.

## Publicar con GitHub Pages
1. Creá un repositorio nuevo en GitHub.
2. Subí `index.html`.
3. En **Settings > Pages**, elegí **Deploy from a branch**.
4. Seleccioná la rama `main` y `/ (root)`.
5. Guardá los cambios.

No necesita servidor ni base de datos para esta versión.
